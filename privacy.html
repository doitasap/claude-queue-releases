개인정보 처리방침

ClaudeQueue는 사용자 개인정보를 수집하지 않습니다.

수집하는 데이터

없습니다. ClaudeQueue는 사용자 데이터를 외부로 전송하지 않습니다.

데이터 저장

모든 작업 기록과 설정은 사용자 컴퓨터에만 저장됩니다.

저장 위치
~/Library/Application Support/com.doitasap.claudequeue/
형식
SQLite 데이터베이스
외부 전송
없음

데이터베이스 파일과 로그는 소유자만 읽을 수 있도록 권한을 좁혀 저장합니다.

네트워크 통신

ClaudeQueue가 직접 보내는 요청은 업데이트 확인 한 가지입니다.

요청 대상
github.com (릴리스 정보)
보내는 내용
없음 — 파일을 내려받기만 합니다
목적
새 버전 존재 여부 확인
이 요청에는 사용자를 식별할 수 있는 정보가 담기지 않습니다. 공개된 릴리스 정보 파일을 내려받아 현재 버전과 비교할 뿐이며, 사용 기록이나 작업 내용은 포함되지 않습니다. 내려받은 업데이트는 서명을 검증한 뒤에만 설치합니다.

그 밖에 사용자가 실행한 Claude Code CLI 명령이 발생시키는 통신은 공식 CLI가 수행하는 것이며 ClaudeQueue의 통신이 아닙니다.

인증 정보

ClaudeQueue는 다음을 수행하지 않습니다.

  • OAuth 토큰 또는 API 키 읽기
  • 인증 정보 저장 또는 전송
  • 로컬에 저장된 Claude Code 인증 정보 접근

모든 인증은 Claude Code CLI가 관리합니다.

기술적 근거

이 방침은 다음 확인에 기반합니다.

  • 인증 정보를 다루는 코드 없음 — api_key·token·ANTHROPIC 관련 코드가 존재하지 않습니다
  • 네트워크를 쓰는 의존성은 업데이터 하나뿐이며, 그 요청 대상은 위에 명시한 릴리스 정보 파일입니다
  • 분석·추적 도구를 포함하지 않습니다
